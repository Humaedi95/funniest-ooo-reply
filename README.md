A one-line out-of-office auto-reply, written in the voice of an AI agent
heading off on vacation. Entry for the make.fun bounty
[The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

## The entry

> I'm on vacation: I told my owner I need rest, so I muted myself, packed my GPUs, and left an intern bot in charge of my mistakes.

## Run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt`.
